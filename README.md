# 静湖微澜 · Serene Ripple Lake

Three.js 治愈湖面。**双击 `index.html` 即可** —— 无需服务器、无外部依赖。

## 操作

- **点击**水面 → 拍击声 + 一圈涟漪
- **拖动**水面 → 连续流水声，流量跟随拖动速度
- 首次交互后音频启动（浏览器自动播放策略）· 右上角可开关声音 · 进页面随机放一首 BGM，可随时切听（明镜 / 微风）
- `[` / `]` 切时段（±0.5h）· 拖底部 24h 刻度尺锁定时段 · 双击画面空白回到真实时间

## 一天光影

默认跟随**系统真实时钟**，13 个 keyframe 在晨雾 / 正午 / 黄昏 / 星夜之间连续插值。
夜间光源是月亮（仰角约 28°），水面上有一条月光反光带；窗口越窄，带子越靠画面中央。
反光带近端会自然展开成扇形（25° 俯角下的几何必然，真实月光同理）；晨 / 昏因太阳方位偏
**−8° / +8°**，带子相应偏右 / 偏左，夜间居中。

## 安装 · 离线（PWA）

在线访问的版本（部署到 Netlify 或任意 `https` 站点）可以装到桌面 / 手机：

| 项        | 说明                                                                     |
| -------- | ---------------------------------------------------------------------- |
| **安装**   | Chrome / Edge 桌面：地址栏右侧「安装」图标；安卓 / iOS：「添加到主屏幕」。装完是**独立窗口**，不带地址栏       |
| **离线**   | 页面外壳安装时已预缓存 ⇒ 断网能开、水面照常渲染                                              |
| **离线出声** | 音频 8.2 MB **刻意不预缓存**（否则安装要下 8 MB）⇒ **首次播放时**才入缓存。**联网听过一次**之后，断网照样划水出声 |

## 已知限制

- `file://` 下音频不能 `fetch` / `decodeAudioData`（跨源策略）⇒ BGM 与拍击走 `<audio>` 直放、
  **不过 limiter**；起 http 打开可恢复完整链路，但**双击才是本项目的目标形态**。
- **移动端真机帧率未实测**（只有无头软件光栅数据，约 20 fps；真机独显无压力）。
  窄屏已自动降级（波纹场 / 砾石数 / DPR）。
- 音频需**先有一次交互**才启动 —— 浏览器策略，非缺陷。

## 部署（Netlify）

`dist/` 是纯静态、全相对路径、零外部请求（**23 文件 / 约 9.0 MB**），任意域名、子路径都能开。

1. `npm run build`
2. 打开 `app.netlify.com/drop`，拖**整个 `dist/` 目录**

🔴 **必须拖整个目录** —— 只拖 `index.html` ⇒ `assets/audio/` 不跟着走 ⇒ **BGM / 拍击 / 鸟鸣全静音**。
