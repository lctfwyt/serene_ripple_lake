# 静湖微澜 · Serene Ripple Lake

一个治愈系的湖面网页。双击 `index.html` 就能打开 —— 不需要服务器，也不需要联网。

## 怎么玩

- **点一下**水面 —— 一声拍击，一圈涟漪
- **按住拖动** —— 连续的水声，拖得越快水声越急
- 右上角可以开关声音；进页面会随机放一首背景音乐，随时可换（明镜 / 微风）
- `[` `]` 切时段（±0.5h）· 拖底部的 24 小时刻度尺锁定时段 · 双击画面空白处回到真实时间

> 声音要等你第一次点击或拖动之后才会响 —— 这是浏览器的规定，不是故障。

## 一天光影

默认跟随**系统真实时钟**，晨雾 / 正午 / 黄昏 / 星夜有不同的光影效果。

白昼太阳光散射，整个湖面波光粼粼。

夜间光源是月亮，水面正中有一条月光柱。

## 装到桌面 / 手机（离线可用）

在线访问的版本（部署到 Netlify 或任意 `https` 站点）可以安装：

| 项          | 说明                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------- |
| **怎么装**  | 电脑 Chrome / Edge：地址栏右侧的「安装」图标；手机：浏览器菜单里的「添加到主屏幕」。装完是**独立窗口**，不带地址栏 |
| **离线**    | 页面本体在安装时就存好了 ⇒ 断网也能打开，水面照常                                          |
| **离线出声** | 音频有 8 MB 左右，**特意不预先下载**（否则装一次就得下 8 MB）⇒ **第一次播放时**才存下来。所以**联网听过一次**之后，断网划水照样有声 |

## 已知情况

- 手机真机流畅度还没实测过；屏幕窄的会自动降低画质。
- 双击打开时声音走的是简化通道（够用）；用本地服务器打开能听到更完整的音效。

## 部署（Netlify）

`dist/` 是一整包静态文件（约 9 MB），放哪个域名都能开：

1. `npm run build`
2. 打开 `app.netlify.com/drop`，把**整个 `dist/` 目录**拖进去

🔴 一定要拖**整个目录** —— 只拖 `index.html` 的话音频文件夹不会跟着走，打开就是一片安静。
