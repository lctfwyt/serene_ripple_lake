## 1. 目标与**范围裁定**

让**构建产物**（`dist/` → Netlify）可**安装到桌面/手机**、可**离线打开**。

### ⚠ 一条刻意的**不对称**（先看这里，别当成漏改）

**本包只改 `app/index.html`（构建入口），不改根 `index.html`（免构建入口）。**

| 为什么 | 说明 |
|---|---|
| PWA 机制在 `file://` 下**根本不生效** | `ServiceWorker` / `manifest` 都要求 `https://` 或 `localhost`。根 `index.html` 是「双击即开」的那条入口 ⇒ 加了也永远用不上 |
| 加了反而**制造失败请求** | 根入口若写 `<link rel="manifest" href="manifest.webmanifest">`，它从仓库根提供时**没有这个文件** ⇒ 每次打开一条 `requestfailed`（`10-assert.spec.mjs` 会把它打进 `netErrors` 报告）。而 `dist/` 里 manifest 就在隔壁，正常命中 |
| 少碰一个冻结文件 | 根 `index.html` 是「不许碰」清单常客（AM-033 已破例一次做改名）⇒ 本包**零必要**不再破例 |

> 镜像纪律（「改样式要改两处」）在这里**不适用**：本条不是样式，是**只在部署形态生效**的能力。

## 3. 图标规格书（**雨桐提供 · 本包唯一阻塞项**）

### 3.1 必需（4 个）

| 文件（放 `app/public/icons/`） | 尺寸 | `purpose` | 背景 |
|---|---|---|---|
| `icon-192.png` | **192×192** | `any` | 可透明 |
| `icon-512.png` | **512×512** | `any` | 可透明 |
| `icon-maskable-512.png` | **512×512** | `maskable` | **必须不透明**（整块铺底） |
| `apple-touch-icon.png` | **180×180** | —（iOS 用） | **必须不透明**（iOS 自己加圆角） |

### 3.2 可选（2 个，好看但非必需）

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `favicon.ico` | 16 / 32 / 48 多尺寸 | 浏览器标签页（**你提到的「指定尺寸组合 ico」就是它**） |
| `favicon.svg` | 矢量 | 现代浏览器标签页（若给 master SVG 则自动有） |

### 3.3 🔴 maskable 安全区（这是唯一"设计上会做错"的一项）

```
┌──────────────────────── 512 × 512 ────────────────────────┐
│  ↙ 出血区（每边 51px）—— 系统可能裁成：圆 / 方 / 水滴 / 圆角 │
│      ╭──────────── 直径 410px（= 80%）────────────╮        │
│      │   🔒 关键图形必须**完全**落在这个圆内        │        │
│      │      （留出安全边距：logo 视觉重心居中心）  │        │
│      ╰────────────────────────────────────────────╯        │
└────────────────────────────────────────────────────────────┘
```

- **底色必须铺满整块**（`maskable` 与 `apple-touch` 不能透明 —— 否则裁完出现黑洞/白边）
- 反例：把 logo 顶到画布边缘 ⇒ 安卓启动器裁成圆形时四角被切掉
- 简记：**「一块满底 + 居中的小 logo（不超 80%）」**

### 3.4 配色方向（建议，审美归你）

页面是**深色水面**（`#0b1418` 底 · `#fallback` 渐变 `#8fb8c9 → #4a7d92 → #1d3b47`）。两个方向：

- **A（推荐）** 深青底 `#0b1418` + 亮水色/白 logo —— 与 App 内一致，桌面图标是"夜晚的湖"
- **B** 水面渐变底 + 白 logo —— 更亮眼，但与 App 打开后的深色略脱节

### 3.5 格式与**交付方式**（重要）

| 问题 | 答案 |
|---|---|
| 只给 SVG 够吗？ | **不够**。`manifest` 图标要 **PNG**（Chrome 也认 SVG，但 `maskable` 与 iOS 兼容性差）。SVG 是**源**，不是交付件 |
| 你该给我什么？ | **① 一个 master SVG（≥512 见方，图案已落在 §3.3 安全区内）**，或 **② 一张 ≥512 的方图 PNG**。其余尺寸由施工方派生 |
| 怎么派生？ | 用**项目已有的无头 Chrome** 截图栅格化（`plan/pw` 链路已装 Chrome）—— **零新增依赖**，不引 `sharp`/`imagemagick` |
| 只有 ICO 行不行？ | 可以拆出 PNG，但 **ICO 通常没做 maskable 安全区设计** ⇒ 若走这条，请**额外告诉我 logo 的安全边距**，否则 maskable 那张要重做设计 |
| 尺寸给错会怎样？ | `manifest` 的 `sizes` 必须与真实像素**逐字一致**（192 写 192），否则 Chrome 拒绝安装 |

> **最短路径**：给我一个 SVG（或一张 512 方图）+ 一句话选 A/B 配色。剩下 6 个文件我来出。

## 4. `manifest.webmanifest` 规格

```json
{
  "name": "静湖微澜 · Serene Ripple Lake",
  "short_name": "静湖微澜",
  "description": "Three.js 治愈湖面 · 轻触水面起涟漪",
  "lang": "zh-CN",
  "start_url": "./",
  "scope": "./",
  "display": "standalone",
  "orientation": "any",
  "background_color": "#0b1418",
  "theme_color": "#0b1418",
  "icons": [
    { "src": "icons/icon-192.png",          "sizes": "192x192", "type": "image/png", "purpose": "any" },
    { "src": "icons/icon-512.png",          "sizes": "512x512", "type": "image/png", "purpose": "any" },
    { "src": "icons/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

| 字段 | 取值理由 |
|---|---|
| `start_url` / `scope` = `"./"` | **相对** ⇒ 部署在子路径 / 任意域名都对（与 `dist` 全相对路径同款） |
| `display` = `standalone` | 安全档（有状态栏、可退出）。**想更沉浸可换 `"fullscreen"`** —— 一句话可切，挂雨桐 |
| `orientation` = `any` | 竖屏也能跑（`hHalf` 收到 12.73°，画面仍成立）。想锁横屏 → `"landscape"` |
| `theme_color` = `#0b1418` | 与页面底色一致（状态栏/地址栏同色） |
| `background_color` = `#0b1418` | 启动闪屏底色，避免白闪 |

## 5. `sw.js` 规格（**本项目异常简单** —— 因为 JS/CSS 全内联）

**核心事实**：`vite-plugin-singlefile` 把 JS/CSS 全塞进 `index.html` ⇒ **壳只有 1 个 HTML**。所以：

| 资源 | 策略 | 理由 |
|---|---|---|
| 壳（`./` = `index.html`）· `manifest.webmanifest` · `icons/*` | **预缓存**（install 时联网拉一次） | 合计几十 KB，秒级 |
| `assets/audio/**`（**8.08 MB**） | **懒缓存**：首次真正播放时入 cache，之后离线可用 | **绝不预缓存** —— 否则安装时下 8 MB，体验崩 |
| 其它 | 网络优先，失败回 cache | — |

**两个必须实测的坑**：

1. **`Range` 请求**：`<audio>` 会发 `Range` 请求，`cache.put` 对 206 响应会抛错。
   ⇒ 拦到音频请求时：**命中 cache 就直接返回 200 + 全量体**；未命中则**去掉 `Range` 头**取全量后入 cache。
   **验收**：联网听一次 → 断网（`context.setOffline(true)`）→ 刷新 → 仍能划水出声。
2. **更新要能发出**：cache 名带版本（如 `srl-v1`）；`activate` 里清旧 cache；配 `skipWaiting()` + `clients.claim()`。
   ⇒ 依赖 `109` 写的 `sw.js` **`must-revalidate`** 头（两者配套，别只做一边）。

**红线**：`sw.js` **不代理** `http(s)` 以外的请求（`file://` 不经过它）· 不缓存非本域请求 · 播放失败不能白屏。

## 6. `app/index.html` 改动（`<head>` 追加，`<body>` 零改动）

```html
<link rel="manifest" href="manifest.webmanifest">
<meta name="theme-color" content="#0b1418">
<link rel="apple-touch-icon" href="icons/apple-touch-icon.png">
<meta name="mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<!-- 可选（若给了 favicon）：
<link rel="icon" href="icons/favicon.ico" sizes="any">
<link rel="icon" href="icons/favicon.svg" type="image/svg+xml">  -->
```

路径用**相对**（`manifest.webmanifest` 而非 `/manifest.webmanifest`）—— 与 `#fallback` / `assets/audio` 同款，保证子路径部署成立。

**🔴 三条不许做**（会踩别人的断言）：

| 红线 | 撞哪条 |
|---|---|
| **不得**往 `app/index.html` 加任何 `<script src>` | `50-brand.spec.mjs` 判据 6 钉死根 `index.html` 的 `<script src>` 序列（本包不动根入口，但形态纪律别坏） |
| **不得**在渲染路径 `src/*.js` 里出现字符串 `brand` 或品牌中文串 | `50-brand.spec.mjs` 判据 7b（本包**已避开 `src/**`**，此处仅备忘） |
| **不得**把 SW 注册写进 `src/99-main.js` | 它是**经典脚本**（根入口也加载）⇒ 语法上不能用 `import.meta`；且属 WP1。**注册放 `app/main.js`** |

## 7. `app/main.js` 追加块（放在文件末尾，`SW.boot()` 之后）

```js
// UP17 / AM-036：PWA —— 仅构建形态注册（dev 不注册，避免干扰 HMR）
if (import.meta.env.PROD && 'serviceWorker' in navigator) {
  window.addEventListener('load', function () {
    navigator.serviceWorker.register('./sw.js').catch(function (e) {
      console.warn('[still_water] SW 注册失败（非致命）', e);
    });
  });
}
```

- `import.meta.env.PROD`：**只有构建产物**注册（`vite build` 时替换为 `true`）⇒ dev server / 根入口都不注册
- 注册失败**只 warn**，绝不影响页面（与 `99-main.js` 的 `safe()` 哲学一致）
- `'serviceWorker' in navigator` 守卫：`file://` / 老浏览器直接跳过
