## 1. 现状 ——「splash」到底是什么（改之前先看清）

「splash」在本项目里**不是新概念**：它是**契约 §4 的既有事件**——

```
splash  { x, z, speed01 }   ← 70-input.js 发（WP2） · 10-audio.js:1678 消费（WP4）
```

也就是**拖动水面时的划水声**。当前由**两层混合**而成：

| 层 | 机制 | 代码锚点 | 听感 / 代价 |
|---|---|---|---|
| **连续「流水」层** | 程序化 WebAudio：目标电平 `flowTarget`（慢拖 `0.10` → 快拖 `0.60`）指数跟随；「水花 spray」+「涌动 body」双层，带 LFO 与低通；停手后 `FLOW_HOLD` 平段 + 长淡出 | `flowCmd` / `flowTick` / `tailShape`（`~:757-830`）· 常量 `~:39-58` | 无缝、随速度耦零文件；**「真实感」有限**（是合成的水声，不是录的水声） |
| **离散「拍击」层** | `<audio>` 元素池直放 4 个 `0.55s` 采样 `slap1~4.wav`（源自 `slap.mp3` 29s 连续戏水，按低频能量挑段，已统一峰值 + 淡入淡出） | `slapPool` / `poolPlay`（`~:251` / `~:540`） | 有"肉感"；每次 `playbackRate` 抖动 `0.88~1.12`；**`file://` 下唯一可行的采样路** |
