## §1 根因（定位到行 · 非推测）

`src/30-scene.js` —— `buildEnv()` 的**第一行**是一道单向闸门：

```js
if (this.env.rebuilds >= ENV_REBUILD_MAX) { return this.env.ready; }   // ENV_REBUILD_MAX = 40（:145）
```

- `env.rebuilds` 只在成功烘图后 `++`，**全库无任何重置**（`SW.resetP()` 只动 `P`；`envEnabled` 翻转只清 `_envLast`，不动 `rebuilds`）。
- ⇒ 累计 40 次重建后，**本会话永久不再烘 env**。早退返回 `this.env.ready`（= `true`）⇒ **静默失效**：`env.err` 不置位、`uEnvReady` 仍 1、面板与断言都看不出来。
- `src/60-water.js:724` 每帧把 `uEnvEq` 重指到 `env.equirect` —— 水面是**忠实消费**方，不是它的问题。

**放大它的第二处缺陷**（`:446-448`）：

```js
if (envDist(s, this._envLast) > ENV_EPS || !this.env.ready) {
  this._envLast = s;              // ① 先提交"已烘到此状态"
  envLive = this.buildEnv(s);     // ② 再烘（可能被 :472 早退）
}
```

① 在 ② 之前 ⇒ 一旦被上限早退，`_envLast` 已前进、下一帧 `envDist ≈ 0` ⇒ **连"下次再来"的机会都没有**，不可自愈。

**为什么拖刻度尺会撞满 40**：`80-ui.js` 拖动走位移增量 → 每次 `pointermove` 都 `setHour()` → `20-time.js refresh()` 换新状态对象 → `envDist > ENV_EPS(0.02)` 即重建。一次「正午拖到深夜」的连续拖动（含松手后的惯性 `fling`）累计重建次数是**几十到上百**量级 ⇒ 单次拖动即可撞满。

## §2 影响面（**比"光带不消失"大得多**）

闸门锁死的是**整张 env 的重建**，不只是光带：

| 消费者 | 冻结后表现 |
|---|---|
| 水面反射 `uEnvEq` | 光带 / 圆斑 / 弥散档**全部冻结**（本 bug 症状） |

| `env.gate` / `env.spread` 只读读数 | 冻结 ⇒ **复核与出图脚本会读到假读数** |

**挂机也会触发**：默认跟随真实时钟，`envDist` 累积约 1.7 分钟触发一次重建 ⇒ **约 70 分钟挂机即锁死**。不是"拖动才有"的边角 bug，是**长时间运行必然发生**。

## §4 实现

**目标一句话**：让「昼夜换档」变成**不可能被预算吃掉**的事件，同时把静默失效改成**有声**。

### §4.1 实际采用（比原「方案 A」更简，但同样杜绝「永久拒绝」）

| # | 原建议 | 实际做法 |
|---|---|---|
| 1 | 门控跨越 = 强制重建 | **不单独做** —— 「**成功才提交** `_envLast`」已保证**最终一致**（配额/静默期只**延后**、不丢失），跨档无需旁路 |
| 2 | 上限改"滑窗预算" | **改成"静默期"**：状态停稳 `ENV_SETTLE_FRAMES = 6` 帧才烘一次 —— 拖动全程 **0 次**重建（比滑窗更省，且"拖动中重建"这一浪费源被直接消除） |
| 3 | 修提交顺序 | ✅ 照做（`_envLast` 只在 `buildEnv` 成功**且** `err` 为空时提交） |
| 4 | 静默 → 有声 | ✅ 新增只读读数 `env.deferred`（被静默期推迟的累计次数）；`rebuilds` 降为纯诊断计数 |
| 5 | 成本护栏 | 天然满足（每帧最多 1 次；静默期下拖动基本为 0） |

**为什么不用滑窗**：滑窗只是把「40 次终身」换成「N 次每窗口」，仍会**推迟**跨档；静默期直接消除"拖动中重建"，且松手后 0.1 s 即补上 —— 更简单、更强。

**代码形态**（`applyTimeState` 内）：

```js
var moved = (envDist(s, this._envSeen) > 0);        // 状态是否仍在动（拖动中每帧换对象）
if (moved) { this._envStill = 0; } else { this._envStill++; }
this._envSeen = s;
var envDirty = (envDist(s, this._envLast) > ENV_EPS) || !this.env.ready;
if (envDirty && (!this.env.ready || this._envStill >= ENV_SETTLE_FRAMES)) {
  envLive = this.buildEnv(s);
  if (this.env.ready && !this.env.err) { this._envLast = s; this._envStill = 0; }   // ★ 成功才提交
} else {
  if (envDirty) { this.env.deferred++; }
  envLive = this.env.ready;
}
```

`buildEnv()` 首行的终身配额闸门**整行删除**（历史留注释）。
