## §3 推荐方案：**环形窗口刻度尺**（不是滑杆换皮）

直接把 range 换成"更好看的 range"**做不到 B（无限拖动）**——原生 range 的两端是硬边界。
推荐把刻度尺做成**24 小时环上的一个滑动窗口**：

```
   ┌─────────────────────────────────────────┐
   │  ·  |  ·  |  ·  |█|  ·  |  ·  |  ·      │   ← 只画"当前时刻 ±N 小时"这一段
   │       21    22    23  00    01    02    │   ← 当前时刻用一根稍亮的竖线 + 刻度数字
   └─────────────────────────────────────────┘
```

要点：
- **数据是环形的**：hour 永远 `mod 24`。窗口边缘越过 24 自然回卷 → **B、C 两条天然成立**，不需要"拖到头再跳回去"的特殊处理
- **交互**：`pointerdown` 记起点 → `pointermove` 累计 **位移增量** → `hour = (startHour + dx * rate) mod 24`。
  用增量而不是绝对坐标，是"无限"的关键
- **视觉减负**：刻度线细（1px）、低不透明度（建议 ≤ 0.45）、**不要实心圆 thumb**，整条只在底部窄带内（高度建议 ≤ 24px）
- **时刻提示**：当前时刻用一根稍亮的竖线即可（不要大圆点）；小时数字可选，字要小

**无障碍**：`input[type=range]` 可以保留但**视觉隐藏**（`opacity:0` 覆盖在刻度尺上，或 `position:absolute` 透明），
这样键盘方向键、`aria-label="时段"` 都不丢。别直接删掉 range 让键盘用户失去控制。

## §4 咔嗒声（跨包接口，判空降级）

UP9 正在实现 `SW.audio.sfxTick(step)`（波次 5 并行，你开工时它还不存在）。

```js
// 每跨过一个刻度触发一次（建议每 1h 一格；觉得太稀就 0.5h）
if (SW.audio && SW.audio.sfxTick) { SW.audio.sfxTick(0.5); }
```

**必须判空**——不存在时静默，**不许报错、不许自己合成声音、不许用 Web Audio 现搓**。
UP9 落地后咔嗒声自动生效，你零改动。（`90-WAVE5.md §4` 耦合 ②）

节流交给 `sfxTick` 内部（它会 ≤ 25ms 去重），你只管"跨格就调"。
