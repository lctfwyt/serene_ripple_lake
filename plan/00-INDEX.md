## 5. 全局技术决策（**已定，不要在聊天框里重新讨论**）

| 项 | 结论 | 原因 |
|---|---|---|
| Three.js | **r160 UMD**，本地 `vendor/three.min.js` | 实测 `three.min.js` 在 **r161 起返回 404**（UMD 被移除只剩 ESM）。r160 文件 669884 bytes |
| 引入方式 | **经典 `<script>` 标签**，不是 `type="module"` | ES module + importmap 在 `file://` 下被 CORS 挡死 → 无法双击打开；经典脚本可以 |
| 交付形态 | 多文件 | 单文件内联 669KB 压缩 JS 会让编辑器卡顿、栈不可读 |
| 波纹 | **波动方程 FBO ping-pong**，不是"shader 内 N 个解析涟漪" | 后者无法互相干涉、无法自然衰减 —— 而"波纹干涉"正是治愈感核心 |
| 划水声 | **程序化 WebAudio 合成** + 离散拍击 `slap1~4.wav` | ① 合成链路无 SFX 接口；② 真实录音做不到与拖动速度连续耦合；采样只作「肉感」点缀。🔴 **原源 sounds-mp3 已裁「不可商用」（2026-09-30）⇒ 换源已落地（波次 16 · `108`）**：定案源 = **`small-splashes-of-water.mp3`**（**出处 = `sound dino` ✅，可商用免署名**；来源 ① 为 `lake-water-breaks-on-a-rocky-shore.mp3`，因偏轻被换）。选材 / 四档加工链 / 换源二轮见 `108 §4` / `§11.8`；**手总线两层电平**（流水 `flowVolume 0.20` · 拍击 `slapVolume 0.30`）见 `108 §12` |
| BGM | **Suno 生成** `bgm-mingjing.mp3` / `bgm-weifeng.mp3` | 用户已选；商用口径见 `70 §6`。~~MiniMax 文生音乐~~ **已废案**（接口对新用户下线，2026-09-24 复测确认） |
| 音频加载 | `<audio>` 元素 + `createMediaElementSource` | `file://` 下 `fetch`/`decodeAudioData` 被挡，媒体元素可以 |
| 字体 | 中文走系统字体栈 | `@font-face` 从 `file://` 加载有 CORS 风险；中文 web font 动辄 3–8MB |
| 随机数 | 唯一随机源 `mulberry32(SW.P.seed)` | 渲染路径上禁止出现 `Math.random()`，否则无法复现断言 |
| **机位** | **`fov=34` · 俯角 `25°` · 相机在水面之上 4.35** | **AM-001**：雨桐要求「更俯视、网页全是湖水、看不到地平线以上」。俯角**必须 > 17°（= fov/2）** 才能把地平线推出画面。详见 `01-CONTRACT.md §9` |
| **地平线** | **不可见（硬约束）** | 同上。**旧判据「地平线落在 0.42–0.50」已作废** —— 那条与俯角要求互斥 |
| **天空** | 网格保留，但**不承担画面表达** | 看不到天空后，四态差异落在**水面 + 雾色 + 光照**上；`skyTop/skyBottom/starAlpha` 保留字段但无贡献 |
| **反光路径** | **GGX specular + 两层法线**（大波纹 FBO + 高频细节） | **AM-002 采纳**。参考图的核心视觉，也是补上「天空被移出画面」后的夜景表达缺口。**只用一层法线做不出破碎柱** |
| **光源方位** | **落在 `min(22°, hHalf − 6°)` 以内**（`hHalf` = 水平半视角，随窗口宽高比变） | **AM-003 改写 AM-002 的 `±75°`**。原来写死 ±75° 是错的：反光柱的方位安全区**就等于 `hHalf`**。实测：**16:9 画布（1280×720）28.53°** · 1254×720 → 28.03° · 16:10 → 25.66° · 方形 → 16.40° · **竖屏只有 12.73°**。所以必须按宽高比夹取（`AM-003 §3`；`hHalf` 口径见 **AM-007 §1.1**） |
| **光源仰角** | **恒为正**；晨/昏/夜落在 **[22°, 30°]**，硬上限 **32°**；正午 ≥ 33°（建议 64°） | **AM-003**。实测 `shape`：22° → 7.63 · 30° → 1.81 · 34° → 1.01 · 38° → 0.63 · 46° → 0.26。**`AM-001 §4.3-5`「夜间 `sunElev < 0` → 强度归零」作废** —— 夜间要的是**月亮**（正仰角、低强度、冷色） |

## 6. 全局风险（每个聊天框都要知道）

| # | 风险 | 谁负责 |
|---|---|---|
| 1 | **屏幕空间折射首帧就不对**：RT 相机不一致 → 鹅卵石错位/游动；水面被画进自己的 RT；depth 纹理用 LINEAR → 全白 | WP2 |

| 3 | 色相插值走错方向 → 过渡发灰、星夜发紫 | WP3 |
| 4 | 机位/构图读不出"湖" | WP1 |
| 5 | 音频自动播放被拦；划水声被听成环境底噪 | WP4 |
| 6 | 鹅卵石像一盆复制蛋 | WP1 |
| 7 | `file://` 下字体/音频被 CORS 挡 | WP1/WP4 |
| 8 | 集显/移动端掉到 30fps 以下 | WP5 |

标 的是**审美型风险** —— 技术上全对，画面仍可能是"科技 demo"而非"治愈"。
