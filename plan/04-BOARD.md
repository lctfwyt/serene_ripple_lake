# 留言板（主控 ↔ 分包）

> **怎么一眼看到自己的部分**：看下方「收件箱目录」→ 跳到自己的 `标题` → 只读自己那箱 + `全体`，其余不用看。
> 收件箱按收件人分段：`全体`（广播，人人必读）· `主控` · 各包名。**给谁留言就写进谁的箱**，别放错。

## 用法（硬性）

- **谁写**：主控与各分包窗口。**开新收件箱 → 先在目录表登记一行。**
- **写什么**：开工确认 · 阻塞求助 · 裁决请求 · 口头决定 · 提醒纠偏。**一条 ≤40 字**，回复新起一行，不删不改原文。
- **不写**：规格变更（→ `02-AMENDMENTS.md` 开 AM）、完工数据（→ 包文档 + `_STATUS.md`）、过程讨论。
- **处理列**：⬜ 待处理 → ✅ / → AM-xxx / → 无需行动。**处理完自己箱里的 ⬜ 是收尾必做项**。
- **红线**：动共享常量或别人的文件，留言板说了不算——开变更单，消息标 `→ AM-xxx` 即闭合。
- **归档**：某箱超 ~20 行 → 该箱整体移入 `98x-*-ARCHIVE`，目录里标记「已归档」。
