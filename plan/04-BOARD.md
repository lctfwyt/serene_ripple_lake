# 留言板（主控 ↔ 分包）

> 收件箱按收件人分段：`全体`（广播）· `主控` · 各包名。**给谁留言就写进谁的箱**。
> **不给雨桐留言** —— 他有意见会提，没提就是没意见。待办一律写成事实陈述，不用请示口吻。
> 包内细节（读数 / 诊断 / 逐档对比）一律进包文档，**板上只留活跃传话**。

## 用法（硬性）

- **谁写**：主控与各分包窗口。开新箱 → 先在目录表登记一行。
- **写什么**：开工确认 · 阻塞求助 · 口头决定 · 提醒纠偏。**一条 ≤40 字**，回复新起一行。
- **不写**：规格变更（→ `02-AMENDMENTS.md` 开 AM）、完工数据（→ 包文档 + `_STATUS.md`）、过程讨论。
- **处理列**：⬜ → ✅ / → AM-xxx / → 无需行动。**收尾时清自己箱里的 ⬜**。
- **红线**：动共享常量或别人的文件，板上说了不算 —— 开变更单，消息标 `→ AM-xxx` 即闭合。
- **归档**：某箱超 ~20 行 → 整箱移入 `98x-*-ARCHIVE`，目录里标记「已归档」。
