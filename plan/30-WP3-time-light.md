## 3. 四个 keyframe

| 时段 | 小时 | 特征 | **光源仰角**（AM-003） | **方位偏移**（AM-003） |
|---|---|---|---|---|
| 晨雾 | 05:30 | 低太阳、高雾密度、去饱和青灰、水偏冷 | **24°** | **−8°** |
| 正午 | 12:30 | 高太阳、清透、高对比、青蓝水色 | **64°** | **0°** |
| 黄昏 | 18:30 | 低太阳、长波光、暖金到玫瑰、雾转暖 | **22°** | **+8°** |
| 星夜 | 22:30 | **月亮**（不是"太阳落下"）、冷蓝、雾密 | **28°** | **0°**（居中 = 主力画面） |

**建议取 8 个 keyframe**（在四态之间再插 09:00 / 15:30 / 20:30 / 01:00），过渡会明显更顺。
但**四态是必须的**，中间点可按需要加。

> ⚠️ **仰角必须单调过渡、任何小时都不许为负。** 夜间是**月亮**（正仰角、低强度、冷色），
> 不是"太阳压到地平线以下" —— 理由见 `02-AMENDMENTS.md AM-003 §2`（那段把 AM-001 §4.3 第 5 条改掉了）。

### 3.1 为什么不能沿用正弦公式

`§4.4` 原来的 `sunElev = sin((hour − 6)/12 · π) × 65°` 会给出**负值**：

| 时刻 | 5.5h | 12.5h | 18.5h | 22.5h |
|---|---|---|---|---|
| 公式给出 | **−8.5°** | 64.4° | **−8.5°** | **−60.0°** |

而 WP2 的 `glitterSpec()` 第一道门就是 `if (Ly <= 0.02) return 0` ——
**照这个公式做，晨雾/黄昏/星夜的反光柱全部为 0，AM-002 的 A 项在夜间等于没做。**
**处理办法：仰角改成 keyframe 直给，删掉公式。**

## 4. 关键实现

### 4.1 环绕插值（0–24h 是环，不是线）

```js
// 找到 hour 落在哪两个 key 之间；注意跨越 24 点的环绕
function getState(hour) {
  // 1. 定位区间 [h0, h1]，t = (hour - h0) / (h1 - h0)
  // 2. smoothstep(t) 让过渡两端更慢
  // 3. 逐字段插值
}
```

`smoothstep(t) = t*t*(3-2*t)` —— 不加的话四态之间会有明显的"折线感"。

### 4.2 ⭐ 颜色插值必须走最短弧

**这是本包最大的审美风险。** 直接对 RGB 线性插值，或者对 HSL 的 H 直接线性插值，
都会让颜色**绕远路**——黄昏的橙到星夜的蓝，可能中途经过绿/灰，画面就"脏"了。

```js
// 正确做法：色相按最短弧插值
function lerpHue(h0, h1, t) {
  let d = h1 - h0;
  if (d > 0.5)  d -= 1;      // 走另一侧更近
  if (d < -0.5) d += 1;
  return (h0 + d * t + 1) % 1;
}
```

**建议走 OKLCH 空间**（感知均匀，插值不会出现"中间发灰"）：
- 可加载 `design-palette-oklch` skill 定这套四态色板
- 落地时把 OKLCH → sRGB 的转换写成一个小函数即可，不需要引入库

### 4.3 色相步长自检（可断言）

**相邻 keyframe 之间最大色相步长应 < 60°。** 超过就说明过渡会明显"跳色"。

```js
// 自检：把 4 个 keyframe 的 sunColor / waterColor / skyTop / skyBottom 的色相排一遍
// assertMaxHueStep(KEYS) < 60
```

### 4.4 太阳位置 —— **🔴 已按 AM-003 重写，不要用旧的正弦公式**

```js
// ❌ 作废（AM-003 §2）：会给出负仰角，反光柱全部消失
// sunElev = Math.sin((hour - 6) / 12 * Math.PI) * 65;

// ✅ 新：仰角由 keyframe 直给 + 环绕插值（与其它字段同一套插值器）
//    晨雾 24° · 正午 64° · 黄昏 22° · 星夜 28°（见 §3 表）
//    中间点可插，但必须单调过渡、任何小时 sunElev > 0
```

```js
// 方位：先按 keyframe 给偏移量（晨 −8° / 午 0° / 昏 +8° / 夜 0°），再按宽高比夹取
// ⚠️ 夹取必须在这里（getState 内部），不能只在 applyTimeState 阶段做 ——
//    否则 probe().sunAz 读到的值与实际光源位置不一致，WP5 的断言会读到没夹过的值。
function clampAz(offsetRad) {
  var cam = SW.scene.camera;
  var hHalfDeg = Math.atan(Math.tan(cam.fov / 2 * Math.PI / 180) * cam.aspect) * 180 / Math.PI;
  var kDeg = Math.min(22, Math.max(7, hHalfDeg - 6));   // 6° 余量；7° 是竖屏保底
  var k = kDeg * Math.PI / 180;
  return Math.PI + Math.max(-k, Math.min(k, offsetRad));
}
```

| 窗口 | `hHalf` | 允许偏移 `kDeg` |
|---|---|---|
| 16:9 桌面 | 28.03° | **22°**（封顶） |
| 16:10 笔记本 | 25.66° | 19.7° |
| 方形 | 16.40° | 10.4° |
| 竖屏 | 12.73° | 7°（保底下限） |

**夜间**：不是"主光强度归零、hemi 接管"，而是**换成月亮** ——
`sunElev 28°` · 冷色（如 `[0.80, 0.88, 1.00]`）· **`sunIntensity ≥ 0.6`** · `glitterGain 1.2`。

> `60-water.js` 里那个 `SUN_I_FLOOR = 0.30` 是 WP2 埋的**安全网**，它会让 `glitterSpec` 照样读到 1.0，
> 但画面上的柱只有 0.30 的亮度 —— **靠它兜底等于假通过**。正常给月光一个 ≥ 0.6 的强度。

### 4.5 驱动优先级

| 来源 | 行为 |
|---|---|
| 默认 | `mode='auto'`，读 `new Date()` 的真实小时 |
| URL `?hour=18.5` | 切 `mode='fixed'`，锁在 18.5 |
| 快捷键 `[` / `]` | ±0.5 小时，切 `fixed` |
| 滑块 `#hour` | 拖动即切 `fixed` |
| 双击画面空白处 | 恢复 `mode='auto'` |
| **窗口 resize** | **重算 `hHalf` 并重新夹取 `sunAz`**（`AM-003 §3`）。不重算的话，把窗口拖窄后反光柱会滑出画面 |

`mode` 切换后必须 `SW.bus.emit('timechange', state)`，否则 WP1 的 scene 不会更新。

### 4.6 UI（`80-ui.js`，全部 JS 创建并 append 到 `#ui`）

**不要改 `index.html`** —— 结构由 WP1 写死。你只往里 append：

| 元素 | id | 作用 |
|---|---|---|
| 声音开关 | `#snd` | 调 `SW.audio.setEnabled(bool)`（WP4 的 API） |
| 时段滑块 | `#hour` | 0–24，调 `SW.time.setHour()` |
| 时段标签 | — | 显示"晨雾 / 正午 / 黄昏 / 星夜"文字 |

设计基调：**极简、低对比、半透明**，不要抢画面。字色 `rgba(255,255,255,.72)` 级别。
声音开关在**首次手势前**应显示为"未启动"状态（`SW.audio.ready === false`）。

## 6. 常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| 色相线性插值 | 过渡中段发灰/发绿 | 走最短弧 + OKLCH |
| 环绕点断裂 | 23:59 → 00:01 画面闪一下 | keyframe 表要闭合成环 |
| 夜间有地下光 | 地平线下照上来的假光 | **光源仰角恒为正**（`sunElev > 0` 永远成立），夜间用月亮而非把强度归零 —— AM-003 §2 |
| **照抄正弦公式** | 5.5h / 18.5h / 22.5h 仰角为负 → **反光柱全部消失** | 仰角改 keyframe 直给，删掉公式 —— AM-003 §6.1 第 1 条 |
| **夜间把 `sunIntensity` 归零** | 靠 `SUN_I_FLOOR` 兜底 → `glitterSpec` 读 1.0 但画面柱只有 0.3 亮度，**假通过** | 月光强度 ≥ 0.6 —— AM-003 §5.3 第 7 条 |
| **`sunAz` 不夹取** | 竖屏 `hHalf` 只剩 12.73°，柱整条滑出画面 | 在 `getState()` 内按 `min(22°, hHalf−6°)` 夹 —— AM-003 §3 |
| 只 emit 不更新 | 改小时画面不动 | 每次变更都要 `emit('timechange')` |
| 星夜过饱和 | 发紫（撞 violet/indigo 禁忌） | 夜键饱和度封顶 |
| 滑块抢焦点 | 拖滑块时页面滚动 | `#ui > * { pointer-events: auto }`（WP1 已配）+ `touch-action: none` |
