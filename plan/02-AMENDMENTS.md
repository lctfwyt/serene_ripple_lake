| AM-030 §1 | AM-029 的 env 重建实现 | 「env 按 `envDist` 惰性触发重建 + **终身 40 次配额**（`ENV_REBUILD_MAX`）」作废 —— 该配额是「白天拖到夜、横向光带不消失」的**根因**（烧光即永久**静默**失效）。改为「状态停稳 `ENV_SETTLE_FRAMES = 6` 帧才烘 + **成功才提交** `_envLast`」；`env.rebuilds` 降为**只读诊断计数**。稳态画面**逐位不变**（30-pixel ③ 用旧基线仍绿） |

## 4. 开新变更单的模板

```
# AM-0xx · 一句话标题
1. 背景/实测依据（可复现，脚本名）
2. 变更内容（契约面 / 代码面 分开列）
3. 影响面（哪些包、哪些文件 —— 不得与他人文件重叠）
4. 逐包动作清单 + 验收判据
5. 应用记录（每包应用后追加：时间 + 验证结果）
```

- 只影响**一个包**的内部修改 → 不开变更单，写进该包文档即可。
- 状态符号：⬜ 未决 → 🔶 部分应用 → ✅ 全部应用并验证 → 归档（总表留一行）。
