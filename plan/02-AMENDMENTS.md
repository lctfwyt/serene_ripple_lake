## 4. 开新变更单的模板

```
# AM-0xx · 一句话标题
1. 背景/实测依据（可复现，脚本名）
2. 变更内容（契约面 / 代码面 分开列）
3. 影响面（哪些包、哪些文件 —— 不得与他人文件重叠）
4. 逐包动作清单 + 验收判据
5. 应用记录（每包应用后追加：时间 + 验证结果）
```

- 只影响**一个包**的内部修改 → 不开变更单，写进该包文档即可。
- 状态符号：⬜ 未决 → 🔶 部分应用 → ✅ 全部应用并验证 → 归档（总表留一行）。
