## §3 全局纪律（四条硬约束，违反即退回）

### ① `file://` 下 **没有** `decodeAudioData`
`src/10-audio.js:57` 有实测结论：file 协议下 `fetch / XHR / decodeAudioData` **全部被拦**。
所以任何新音效都**必须走 `<audio>` 元素池**（同 `slapPool`，见 314-330 建池、378-390 播放），
`AudioBuffer` / `BufferSource` 路线在双击入口是**死路**，只在 http 下能响 → 两入口行为会分裂。

### ② 随机只能用 `rng`，禁止 `Math.random`
`src/10-audio.js:138` 有唯一随机源 `rng`（可被 `?seed=` 之类钉控，保证可复现）。
鸟声间隔、音高抖动、BGM 随机首播——**一律走 `rng`**。

### ③ 两入口等价 + 不改断言阈值
`file://` 双击 与 `dist/` 两入口都要验。改了 `src/` 就要 `npm run build` + `npm run pw:dist:snapshot` 重落基线。
**断言阈值一律不许改**——受影响就报前后两套读数，重标由主控做。

### ④ 文档写作纪律（主控本轮刚修过一轮）
- Markdown 表格单元格里**禁止出现管道字符**（裸写或反斜杠转义都不行 —— 渲染器会按它切列，整张表从那行起碎掉）→ 绝对值用 `‖`（U+2016），"或/并集"用 `∣`（U+2223）
- 行尾一律 **LF**（`.gitattributes` 已锁 `* text=auto eol=lf`）

## §5 冻结的交叉接口（UP9 实现 · UP10 消费）

```js
// SW.audio.sfxTick(step) —— 刻度尺咔嗒声（AM-010 新增）
//   step  number  可选，0~1 的"力度/音高"提示（默认 0.5）；实现方可用于音量或音高微调
//   返回  boolean 是否真的出声了（未就绪/静音/开关关闭时返回 false）
//   约束  · 必须走 <audio> 元素池（file:// 铁律）
//         · 必须是"短、干、轻"的木质咔嗒，不得带混响尾（拖动时会密集触发）
//         · 必须受 #snd 静音开关管辖
//         · 必须自带节流（建议 ≤ 25ms 内重复调用只出一声），防止快速拖动糊成一片
SW.audio.sfxTick(step);
```
